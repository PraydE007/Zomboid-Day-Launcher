# 🧟‍♂️ Zomboid Day Launcher

Сучасний високопродуктивний лаунчер для **Project Zomboid** з інтегрованою системою керування репозиторіями, автооновленням конфігурацій, патчів, безпековим скануванням та підтримкою автономних фонових процесів.

---

## ✨ Основні можливості

- 🎮 **Сучасний Gamer UI (Dark Theme)**: Кастомне безрамкове вікно з градієнтами, статусними бейджами, аніме-банером (`D:\Pictures\Anime Zomboid Day.png` / `assets/hero.png`) та плавною навігацією.
- 📦 **Розумна система маніфестів (`launcher-manifest.json`)**:
  - Централізоване визначення загальної версії проєкту (`project.version`).
  - Покрокове налаштування встановлення (`install_steps`) із чітким порядком черги (`order`).
  - Підтримка динамічних змінних шляхів: `{GAME_DIR}`, `{USER_ZOMBOID_DIR}`, `{MODS_DIR}`.
  - Автоматична валідація цілісності встановлених файлів (`validation.required_files`).
- 🔄 **Гнучке керування чергою репозиторіїв**:
  - Підтримка як локальних папок (`C:\Users\user\Desktop\Zomboid-Day-Launcher-Files`), так і віддалених Git-репозиторіїв (`https://github.com/KodeMannn/PZ-ModGuard.git`).
  - Зручне налаштування черги кнопками **Вгору (▲)** та **Вниз (▼)** прямо в інтерфейсі вкладки «Налаштування».
  - Можливість увімкнення/вимкнення окремих компонентів чекбоксами.
- 🚀 **Динамічні кнопки запуску**:
  - Якщо файли ще не встановлено або знайдено оновлення: активна кнопка **📥 ВСТАНОВИТИ ВСЕ**.
  - Якщо все встановлено та актуально: 2 кнопки — **▶ СТАРТ** (стандартний запуск з оптимізованими JVM параметрами) та **⚙ ДЕБАГ СТАРТ** (запуск з дебаг-прапорцем `-debug` та відкриттям консолі).
- 📟 **Вбудована системна консоль та автономні процеси**:
  - Усі CMD-процеси, запуск гри та логи відображаються у вкладці **Консоль** у реальному часі.
  - **Автономність процесів**: гра запускається у відокремленій групі процесів (`CREATE_NEW_PROCESS_GROUP`). При закритті або виході з лаунчера **процес гри та його консоль не закриваються** і продовжують стабільно працювати!
  - Інтерактивний рядок для виконання довільних CMD-команд із виведенням у термінал.
- 🔔 **Інтеграція із системним треєм (System Tray)**:
  - За замовчуванням при старті гри лаунчер автоматично ховається в трей Windows із виведенням системного сповіщення.
  - Контекстне меню трея дозволяє в 1 клік відкрити лаунчер, переглянути консоль або запустити гру.

## 🛠 Структура проєкту

```
Zomboid-Day-Launcher/
├── assets/                       # Ресурси лаунчера (іконка, фонове зображення)
│   ├── hero.png                  # Фоновий банер
│   ├── icon.png                  # PNG-іконка
│   └── icon.ico                  # Системна іконка
├── core/                         # Ядро та бізнес-логіка
│   ├── config.py                 # Керування конфігурацією та автопошук гри
│   ├── manifest_parser.py        # Парсер та валідатор launcher-manifest.json
│   ├── repo_manager.py           # Синхронізація Git та локальних папок
│   ├── installer.py              # Фоновий воркер встановлення та копіювання
│   ├── version_checker.py        # Перевірка версій та статусу
│   └── process_manager.py        # Автономний запуск процесів та стрімінг логів
├── ui/                           # Графічний інтерфейс (PyQt6)
│   ├── theme.py                  # Стилі та QSS-тема оформлення
│   ├── main_window.py            # Головне безрамкове вікно та системний трей
│   ├── tabs/
│   │   ├── home_tab.py           # Вкладка «Головна» (банер, кнопки, картки)
│   │   ├── settings_tab.py       # Вкладка «Налаштування» (шляхи, черга репозиторіїв, RAM)
│   │   └── console_tab.py        # Вкладка «Консоль» (живий термінал, фільтр, CMD-рядок)
│   └── dialogs/
│       └── repo_dialog.py        # Діалог додавання та редагування репозиторіїв
├── main.py                       # Головна точка входу
├── launcher.bat                  # Скрипт швидкого запуску в один клік
└── requirements.txt              # Залежності Python
```

---

## 🚀 Як запустити

1. Переконайтеся, що встановлено необхідні бібліотеки:
   ```bash
   pip install -r requirements.txt
   ```
2. Запустіть лаунчер:
   - Подвійним кліком на `launcher.bat`
   - Або через термінал:
     ```bash
     python main.py
     ```
