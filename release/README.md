# 📦 Release Folder

У цій папці створюється фінальний скомпільований файл **`Zomboid-Day-Launcher.exe`**.

### Як створити новий білд:
Просто запустіть у корені репозиторію:
* **Подвійним кліком**: `build.bat`
* **Або через термінал**: `python build.py`

Скрипт автоматично упакує всі ресурси (`assets/`, `font/`, іконки, PyQt6) в один автономний файл `.exe`.
